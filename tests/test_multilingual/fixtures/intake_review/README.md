# Historical intake review fixtures

These snapshots preserve regression coverage for gender repair lineage and the
reviewed corrections applied on top of it. They are not approvals of the
current maps. Model decisions and source/map digests are unchanged. Absolute
machine paths in gender requests are replaced with repository-relative paths;
reviewer attribution in corrections is retained because it participates in the
pinned maps' approval identity. Authoring checkpoints, review exports, and
internal discussion are intentionally not distributed.
