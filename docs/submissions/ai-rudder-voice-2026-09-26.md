## System boundary

The benchmark connects to one Realtime-compatible interface, runtime model ID `airudder-voice-v1`. Behind it are VIE, internal domain scaffolds and a single Gemini `gemini-3.7-flash` tool-loop agent via Google's OpenAI-compatible API. This is not a dual-brain experiment. ASR: Deepgram `nova-3`, 8 kHz. Agent TTS: ElevenLabs `eleven_flash_v2_5`.

Sessions route by normal benchmark-visible policy/tools, not hidden answers or task IDs. Internal scaffolds add conversation and domain operating rules while preserving the benchmark policy. Tools execute in the stock harness; requests/results cross the normal agent interface. The only stock source change is the disclosed +18/-0 transport hook. Product-internal scaffolds are not represented as an unmodified generic LLM.

## Simulator and protocol

Voice user simulator v1.0. Standard generation: `gpt-4.1-2025-04-14`, temperature 0. Custom generation: `gpt-5.5-2026-04-23`, `reasoning_effort=xhigh`. This non-default simulator is why the latter is Custom; the agent is unchanged.

NL assertions: `gpt-4.1-2025-04-14`; hallucination review: `claude-opus-4-5`, three retries, no auto-review. Tick 0.2 seconds, maximum 1200 virtual seconds, voice seed 300, domain concurrency 6/3/12. Tracks ran sequentially on 2026-09-26: Standard 01:08:36–02:42:44 UTC; Custom 02:45:23–04:52:55 UTC.

User TTS `eleven_v3` uses external-account Voice Design batch v4 (design model `eleven_ttv_v3`, seed 20260925, seven-persona mapping SHA256 prefix `6c65ae3e684773a9`). Regular uses five personas. This batch was reused with permission, not regenerated for this run. These are not Sierra-internal voices; equivalence to Sierra-voice results is not claimed.

Custom xhigh has actual Chat Completions HTTP observations for retail/airline. Telecom tool requests used Responses API, outside the observer's coverage. Invocation logs contain xhigh and a separate same-version offline serialization probe preserves it; that probe is not a live trace of every telecom request.

Standard had two 50s brain-call timeouts: airline task 20 failed; the affected telecom task later passed. This association does not prove the airline failure cause. No manual interruption or best-of selection was used.

## Metrics and limitations

Official interaction metrics are generated by pinned upstream `tau2 submit prepare` from retained tick trajectories and preserved unchanged. `tau2 submit validate` checks trajectory format/tasks/trials and Pass^k; at this pin it does not independently recompute interaction metrics. The latter differ from wall-clock speech-stopped → next output-started measurements, which include fillers and possibly delayed old-generation output and are not semantic TTFS or pure provider latency.

Benchmark and endpoint ran on the same Virginia host via loopback; supplier APIs used external networks. This run does not validate public WSS or isolate a causal network advantage. Cross-region comparisons have not proven deployment equivalence.

Owner declaration (Yechang Hu, confirmed 2026-09-26): the submitted system was not trained specifically on τ-bench tasks, rewards or evaluation data, and did not access hidden task goals, reference answers/actions, evaluator state or other benchmark data outside the standard agent interface. This statement is provided by the owner; a passing validator does not independently establish training provenance.

Separately from the scored batch, three Standard/regular tasks passed through the public WSS gateway on 2026-09-26 with audio, tools and scoring. The paid client was on the service host; an independent Mac tested TLS/anonymous rejection, not full speech. Smoke hallucination review was disabled. This smoke does not establish official acceptance or long-duration capacity. The r2 package revision incorporates the published blog reference and owner declaration without changing trajectories. Official evaluator access and service-window coordination remain handoff items.
