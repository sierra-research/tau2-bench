## Problem Statement

tau2_agent needs shared utilities for SSE streaming during long-running evaluations. Both the structured path (GymOrchestrator in 004) and natural language path need:

1. **Progress tracking** - Calculate and format evaluation progress (percent complete, elapsed time)
2. **Event building** - Create ADK Event objects with tau2-specific metadata
3. **A2A compliance** - Events must convert correctly to A2A TaskStatusUpdateEvent/TaskArtifactUpdateEvent
4. **Trace context** - Expose evaluation_id and task_id for OTel/Datadog instrumentation (007-datadog)

Additionally, the **existing `RunTau2Evaluation` tool** must be updated to use these utilities, enabling:
- SSE streaming for NL path evaluations (before 004-gym is implemented)
- Trace context for 007-datadog integration

**Note**: Routing logic, GymOrchestrator, Docker entry point, and AgentBeats message parsing are covered in [004-gym-evaluation](../004-gym-evaluation/spec.md).

## Design Principles

1. **Stateless utilities** - All functions take input and return output, no side effects
2. **A2A protocol compliance** - Use standard task lifecycle states (submitted, working, completed, failed)
3. **ADK native events** - Create ADK Event objects; ADK handles A2A conversion
4. **tau2.* namespace** - All tau2-specific metadata uses `tau2.` prefix to avoid collisions

### A2A Task Lifecycle States

Per [A2A Protocol Specification](https://a2a-protocol.org/latest/specification/):

| State | Description |
|-------|-------------|
| `submitted` | Task created and acknowledged |
| `working` | Active processing |
| `completed` | Successfully finished (terminal) |
| `failed` | Processing failed (terminal) |

## Core Components

### 1. EvaluationProgress

Tracks evaluation progress for streaming updates.

```python
@dataclass
class EvaluationProgress:
    """Track evaluation progress for streaming updates."""
    total_tasks: int
    completed_tasks: int = 0
    current_task_id: str | None = None
    current_trial: int = 1
    total_trials: int = 1
    started_at: datetime | None = field(default_factory=lambda: datetime.now(timezone.utc))

    @property
    def percent(self) -> int:
        """Calculate completion percentage (0-100)."""
        if self.total_tasks == 0:
            return 0
        return int((self.completed_tasks / self.total_tasks) * 100)

    @property
    def elapsed_seconds(self) -> float:
        """Calculate elapsed time since start."""
        if not self.started_at:
            return 0.0
        return (datetime.now(timezone.utc) - self.started_at).total_seconds()

    def to_metadata(self) -> dict[str, any]:
        """Convert to tau2-namespaced metadata dict."""
        return {
            "tau2.progress": self.percent,
            "tau2.completed_tasks": self.completed_tasks,
            "tau2.total_tasks": self.total_tasks,
            "tau2.current_task_id": self.current_task_id,
            "tau2.elapsed_seconds": round(self.elapsed_seconds, 2),
        }

    def increment(self, task_id: str | None = None) -> None:
        """Increment completed count and optionally update current task."""
        self.completed_tasks += 1
        if task_id:
            self.current_task_id = task_id
```

### 3. tau2.* Metadata Namespace

All tau2-specific metadata uses the `tau2.` prefix:

| Key | Type | Required | Description |
|-----|------|----------|-------------|
| `tau2.state` | string | **Yes** | Task state (submitted/working/completed/failed) |
| `tau2.progress` | int | **Yes** | Percent complete (0-100) |
| `tau2.evaluation_id` | string | **Yes** | Evaluation ID from 002-evaluation-store |
| `tau2.completed_tasks` | int | No | Tasks completed so far |
| `tau2.total_tasks` | int | No | Total tasks in evaluation |
| `tau2.current_task_id` | string | No | Currently evaluating task ID |
| `tau2.elapsed_seconds` | float | No | Seconds since evaluation started |
| `tau2.domain` | string | No | Evaluation domain (airline, retail, etc.) |
| `tau2.error` | string | No | Error message (for failed state) |
| `tau2.error_code` | string | No | Error code (for failed state) |

### 4. RunTau2Evaluation Integration

Update the existing `RunTau2Evaluation` tool to use streaming utilities:

```python
# tau2_agent/tools/run_tau2_evaluation.py (MODIFIED)

class RunTau2Evaluation(BaseTool):
    """Run tau2-bench evaluation with streaming and trace context."""

    async def run_async(self, *, args: dict, tool_context: ToolContext) -> AsyncIterator[dict]:
        # Create evaluation session (002-evaluation-store)
        evaluation_id = await self.session_store.create_session(...)

        # Initialize progress tracking
        progress = EvaluationProgress(total_tasks=num_tasks)

        # Emit submitted event
        yield create_adk_progress_event(
            invocation_id=tool_context.invocation_id,
            state="submitted",
            message=f"Starting {domain} evaluation",
            evaluation_id=evaluation_id,
            progress=progress,
        )

        # Run evaluation with progress callbacks
        for task_result in self._run_evaluation(...):
            progress.increment(task_id=task_result.task_id)

            # Emit working event (SSE streaming)
            yield create_adk_progress_event(
                invocation_id=tool_context.invocation_id,
                state="working",
                message=f"Completed {task_result.task_id}",
                evaluation_id=evaluation_id,
                progress=progress,
            )

        # Emit completed event with results
        yield create_adk_result_event(
            invocation_id=tool_context.invocation_id,
            evaluation_id=evaluation_id,
            results=aggregated_results,
        )
```

**Trace Context Exposure:**

The tool exposes context for OTel instrumentation (007-datadog):

```python
# Context available for tracing
trace_context = {
    "evaluation_id": evaluation_id,      # Correlates all spans in evaluation
    "domain": domain,                     # airline, retail, etc.
    "task_id": current_task_id,          # Current task being evaluated
    "agent_endpoint": agent_endpoint,     # Agent under test
}
```

007-datadog can instrument this tool by wrapping calls with spans that include this context.

## Requirements

### Functional Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| FR-001 | Provide `EvaluationProgress` dataclass for tracking progress | P0 |
| FR-002 | Provide `create_adk_progress_event()` for progress events | P0 |
| FR-003 | Provide `create_adk_error_event()` for error events | P0 |
| FR-004 | Provide `create_adk_result_event()` for result artifacts | P0 |
| FR-005 | All events include required metadata: `tau2.state`, `tau2.progress`, `tau2.evaluation_id` | P0 |
| FR-006 | Support A2A task states (submitted, working, completed, failed) | P0 |
| FR-007 | Events convert correctly to A2A types via ADK | P0 |
| FR-008 | Update `RunTau2Evaluation` to use streaming utilities for SSE progress | P0 |
| FR-009 | Expose trace context (evaluation_id, task_id, domain) for OTel instrumentation | P0 |

### Non-Functional Requirements

| ID | Requirement |
|----|-------------|
| NFR-001 | Evaluation continues if SSE connection drops; results retrievable from 002-evaluation-store |
| NFR-002 | Event builder functions are stateless and thread-safe |
| NFR-003 | Progress tracking supports concurrent evaluations (no shared mutable state) |
