# Portuguese voice + acoustic assets

Generated by `tau2 factory generate-assets --lang pt` (ElevenLabs).
All audio is **16 kHz PCM mono WAV**.

- **continuous beds** (`continuous/pt_BR/`): real generated locale beds
  (outdoor traffic + TV-news-over-kitchen), authored on the fly from the pack's
  locale info. Filenames mirror the English beds they replace.
- **bursts**: constant across locales — the presets reference the shared English
  burst files (`car_horn.wav`, `engine_idling.wav`, `dog_bark.wav`), NOT per-locale
  copies.
- **voices**: designed per persona from its `tts_voice_prompt`; pinned `voice_id`s
  live in `pack.yaml`.

## Provenance
- Beds: [`acoustic_rationale.yaml`](./acoustic_rationale.yaml) (prompts, scripts,
  models, durations).
- Voices: [`voice_rationale.yaml`](./voice_rationale.yaml) (design prompt, model,
  audition text, voice_id per persona).

Regenerate: `tau2 factory generate-assets --lang pt --force`.
