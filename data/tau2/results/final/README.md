# Original τ²-bench paper results (June 2025)

These trajectories are the results reported in the original τ²-bench paper.
They were produced with the June 2025 task sets, before the task fixes that
shipped in v1.0.0. The airline and retail tasks recorded here therefore differ
from the current base tasks, and `tau2 submit` task verification rejects them
(airline: 29 tasks differ, retail: 114). Telecom is unchanged and verifies.

They are kept as a historical record of the paper's numbers. They are not
leaderboard submissions and are not used by any code or test. For results that
verify against the current 1.x tasks, run with the v1.0.1 release or later; the
base task sets have not changed since v1.0.1.
