# Supporting language-pack reviews

This directory contains final native-speaker inputs used to define and check the
five language conditions. They are independent of the judge-validation and FCE
tables.

- `language_review.csv` combines 58 speaker observations with 78 retained
  language-factor clauses. It covers Spanish (`es`), Brazilian Portuguese (`pt`),
  Hindi (`hi`), Korean (`ko`), and Mandarin Chinese (`zh`).
- `call_experience.csv` contains supplemental call-level findings. This was not a
  balanced evaluation packet: it contains 2 Spanish, 20 Portuguese, 20 Korean,
  16 Mandarin, and no Hindi rows. The balanced cross-language caller review is
  the 30-calls-per-language FCE table in `../user_sim_review/fce/`.
The archive includes only final retained language-factor clauses and rows for the
five paper conditions.
